DWG 批量转 PDF（便携版）使用说明
====================================

一、运行前必须确认的事
------------------------------------
1. 这台电脑上装了 **完整版 AutoCAD**（正式版/教育版都行），并且能正常打开 DWG 文件。
   - 不支持 AutoCAD LT（LT 没有自动化接口，程序会报「无法启动 AutoCAD」）。
   - 不支持看图软件、中望/浩辰等其它 CAD。
   - AutoCAD 的版本要能打开待转换的 DWG：图是 2024 存的、同事机器上是 2020，
     AutoCAD 自己就打不开，程序也只能报错。版本太老时让对方存成低版本 DWG。
2. 系统是 **64 位 Windows 10 / 11**（exe 本身是 64 位程序，Win7/8 跑不起来）。
3. 不需要安装 Python，不需要装 VC++ 运行库、.NET，也不需要装 Adobe 之类做 PDF 的软件：
   这些 exe 里都带好了，拷过去双击就能用。
4. 输出目录必须是**可写**的：程序要往里写 PDF（先在旁边写 .part 临时文件再改名）。
   只读共享盘、C:\Program Files 下面都不行。
5. 运行本程序的身份要和 AutoCAD 一致：AutoCAD 用「管理员身份」开着、本程序却用普通身份
   双击，Windows 会拦住两个进程之间的通信，表现是「无法启动 AutoCAD」。
   要么两个都用管理员，要么两个都普通。

二、怎么用
------------------------------------
1. 把 DWG2PDF.exe 放到一个**能写入**的目录，例如桌面、D 盘新建一个文件夹。
   （不要放 C:\Program Files 里，程序会在自己旁边写「run.log」，那里没权限）
2. 双击 DWG2PDF.exe。
   第一次运行时 Windows 可能弹「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」即可（这是所有未签名个人程序的正常提示）。
3. 稍等 5~15 秒（单文件 exe 首次运行要先把自己解压到临时目录，比以后几次慢），
   默认浏览器会自动打开操作界面（地址是 127.0.0.1 开头的本机页面，只有本机能访问）。
   如果没自动打开，看程序目录下的 run.log 里写的端口号，
   在浏览器手动输入：http://127.0.0.1:8791（8791 被占用时会自动换成 8792/8793）。
4. 在界面里：
   - 点「选择」挑 DWG 所在文件夹（支持中文路径，可直接粘贴路径后回车）
     v2.7.0 起会**记住上次打开过的文件夹**：下次再点「选择」，直接落在上次用过的
     那个文件夹上，不用再从用户目录一层层点进去。DWG 文件夹和输出文件夹各记各的。
   - 输出目录不用管：会自动填成「该文件夹\PDF」，转换时自动新建这个 PDF 文件夹；
     想放到别处点「选择」自己挑，改乱了点旁边的「默认」就回到「该文件夹\PDF」
   - 「一个 DWG 的输出」二选一：
     · 合并成 1 个 PDF（多页，每页一张图纸）——默认，文件名用 DWG 名
     · 每张图纸各出 1 个 PDF——文件名用图纸名
   - 「合并时 LAYOUT 图排第 1 页、BOM 图排第 2 页」默认**不勾**（v2.3.0 起）：
     勾上以后，布置图（LAYOUT）放第 1 页、物料清单（BOM）放第 2 页，其余图保持原顺序；
     不勾就完全按图纸顺序出。判断不出来、或同类型有多张时不会动页序，日志里会说明。
     页序本身按布局空间的选项卡序号排：布局1 第 1 页、布局2 第 2 页……与 AutoCAD 里看到的标签顺序一致。
   - 「纸张大小」默认 **A1**（v2.3.0 起）：图纸比 A1 小（A3/A4 的详图、系统图）就等比放大到 A1 出图，
     字更大、打印更清楚；图纸本身比 A1 大（A0 的布置图）则保持原尺寸，不会被缩小。
     也可以选 A0/A2/A3/A4；要看图纸原本的幅面就选「自动（按图纸本身尺寸）」。
   - 需要连子文件夹一起转，勾「包含子文件夹」
   - 想让输出按原目录结构分开放，「输出保持目录结构」默认已勾选（不需要就取消）
   - 点「开始转换」
5. **第一次转换会先启动 AutoCAD，日志会停在「正在启动 / 连接 AutoCAD」30~60 秒，这是正常的**，
   之后才会逐个文件出图。转换期间不要去动 AutoCAD，也不要关它。

三、结果在哪
------------------------------------
输出目录里就是 PDF。
- 默认：一个 DWG 出一个多页 PDF（文件名就是 DWG 名），一页一张图纸，
  页序按 AutoCAD 里布局选项卡的顺序（布局1 第 1 页、布局2 第 2 页……），不做调整
  （勾了「LAYOUT 图排第 1 页、BOM 图排第 2 页」才把这两类图提前）。
- DWG 里留着没用上的空布局（布局9、布局10…）不会出成空白页，日志会写「空布局不出页」。
- 如果选了「每张图纸各出 1 个 PDF」：每个布局出一个 PDF，文件名取布局名或标题栏里的图名。
- 有些图的布局里「白纸和图形错开」（图不在纸面上），程序会按图纸内容重新框定：
  装得下就 1:1，装不下就按「布满图纸」缩放到本页，整张图完整、不裁切。

四、出问题时
------------------------------------
1. 先看程序目录下的 **run.log**，它会记录每次点击有没有到达后台、报了什么错。
2. 常见情况：
   - 「无法启动 AutoCAD」→ AutoCAD 没装好/没激活，或被系统权限挡住（试试右键以管理员身份运行）
   - 转换中报「AutoCAD 正忙，N 秒后重试」→ 正常现象，程序会自动重试，不用管
   - 每页四周一大圈白边、图缩在页面中间 → 这张图的图框只有纸张的几分之一（页面设置和图纸对不上），
     v2.1.3 起会按图框铺满纸张，四周只留 1 mm
   - 页面上下有大片空白、左右被裁掉一截 → 图纸是横的，但页面设置里那张纸只有竖版写法
     （DWG To PDF 的 A0 固定写成 841×1189）。v2.2.0 起按「纸的实际方向 + 出图旋转」
     算真实页幅，横图自动出成横版页并 1:1 铺满
   - 一个 DWG 明明有好几张图，却只出了一页、图被压成细细一条 → 这几张图是并排画在
     模型空间、外面只套了一个装饰大框。v2.2.0 起外框又长又扁（长宽比 ≥1.8）时，
     会找框内重复出现的同款图签块，按它们一张一页拆开
   - 好几张图挤在一页、可外框和分割线都没有 → 这几张图是「整张图纸做成一个块」并排画的。
     v2.3.0 起会找同名同尺寸、互不重叠、加起来占其并集 ≥85% 的块，按它们一张一页拆开
   - 图只占纸的左半边、右边一大片空白 → 页面设置里的「打印窗口」比纸还大。
     v2.3.0 起出图前会检查，窗口超出纸幅就按图纸内容重新框定后再出
   - 打印出来字太小 → 把「纸张大小」调到 A1（或 A0）。图纸比纸小会等比放大，图纸比纸大则不变
   - 转换很慢、一页要等十几二十秒 → 图纸原来的打印设备出不了 PDF（比如同事自定义的
     M_PDF.pc3，本机没有这个绘图仪配置），AutoCAD 收到指令既不报错也不生成文件，
     只能等超时再换设备。v2.4.0 起只认 AutoCAD 自带的 PDF 设备，其余直接用
     DWG To PDF.pc3，不再白等（实测 4 页 A0 从 113 秒降到 33 秒）
   - 图纸很复杂时，识别要十几秒 → 图里块参照/文字太多（2395 个块、2317 个字）时，
     每取一个属性都要跨进程问一次 AutoCAD，约 1~3 ms。v2.4.0 起先取名字/位置再筛，
     2395 个块参照的图从 26 秒降到 13 秒
   - PDF 里有整页空白（只剩纸边一条线） → DWG 里留着没用上的空布局（布局9、布局10…），
     在 CAD 里手动打印也是白纸。v2.5.0 起整页没有图形和文字的直接不出页，
     日志会写「空布局不出页：布局12」，最后汇总「空布局 N 个已跳过」
   - 某页只有图框和标题栏、图没出来 → 该布局的视口是空的（图层关闭、视口冻结、
     外部参照没加载）。v2.5.0 起日志会提示「几乎没有图形，只出到图框和文字，请核对」
   - 日志出现「⚠ 疑似重复图框：第 2 张、第 3 张图内容完全相同」→ 这两个图框一模一样
     （块名相同、属性值也相同），出图就成了两页重复的图。**不是程序出错**，
     v2.6.0 起会点名提示；去 CAD 里删掉多余的那个图框再转即可。
     （只查「整张图纸做成一个块」的画法，空图框块里散画图元的查不出来）
   - 杀毒软件拦截 → 把 exe 加入信任/白名单
   - 界面打不开 → 端口被占用，关掉旧的 exe 进程重新双击
   - 点「选择」没落在想要的文件夹 → v2.7.0 起会记住上次的位置；想让它从用户目录
     重新开始，删掉程序旁边的 dwg2pdf_state.json（只存路径，删了不影响任何设置）
3. 不要同时双击多个 exe，程序会自动复用已开的后台，只会多开一个浏览器标签。
4. **换了新版本的 exe 但现象没变化？**先看界面标题右边的版本号（如 v1.9.1）：
   - 版本号与你下载的新版一致：说明新版已生效。
   - 版本号是旧的或没有：说明后台还跑着旧程序。点界面里的「退出程序」，
     或到任务管理器结束 DWG2PDF.exe，再双击新的 exe。
     （v1.9.1 起会自动识别并关掉旧版本实例，不必手动结束）

五、卸载 / 迁移
------------------------------------
没有安装过程，删除 exe 即可。换电脑直接拷这个 exe（或整个压缩包）。
程序旁边可能多出几个运行时文件，一并删掉也不会有残留：
run.log（日志）、dwg2pdf_state.json（上次打开的文件夹）、start_error.log（出错时才有）。
