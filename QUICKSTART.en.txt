DWG2PDF (portable) — quick start
====================================

1. What the other PC must have
------------------------------------
1. A **full AutoCAD installation** (regular or education licence) that can open the DWG files.
   - AutoCAD LT is NOT supported (it exposes no automation interface; you get "Cannot start AutoCAD").
   - Viewers, ZWCAD, GstarCAD etc. are NOT supported.
   - AutoCAD must be able to open the target DWGs: a DWG saved by 2024 will not open on a 2020 seat.
2. 64-bit Windows 10 / 11 (the exe itself is a 64-bit program).
3. No Python, no VC++ runtime, no .NET, no PDF printer driver — everything is inside the exe.
4. The output folder must be **writable** (the app writes a .part file next to the PDF, then renames it).
   Read-only shares and C:\Program Files do not work.
5. Run the app with the same privilege level as AutoCAD: AutoCAD started "as administrator" plus the app
   started normally means Windows blocks the cross-process COM call ("Cannot start AutoCAD").
   Either both normal or both elevated.

2. How to run
------------------------------------
1. Copy DWG2PDF.exe into a **writable** folder (Desktop, a new folder on D:, ...).
2. Double-click DWG2PDF.exe.
   Windows may show "Windows protected your PC" on the first run: More info -> Run anyway.
3. Wait 5-15 s (a one-file exe unpacks itself on the first run); your browser opens the control page
   (a 127.0.0.1 address, reachable from this machine only). If nothing opens, look at run.log for the
   port and open http://127.0.0.1:8791 manually (8791 may become 8792/8793 if busy).
4. On the page:
   - The UI is **bilingual** (since v2.8.0): English or Chinese is picked from the system on start-up.
     The `English` / `中文` button at the right of the title switches everything instantly, including
     the log lines produced afterwards; the choice is remembered in dwg2pdf_state.json.
   - *Browse* to the **DWG folder** (Chinese paths are fine; you can also paste a path and press Enter).
     Since v2.7.0 the picker reopens at the folder you used last (DWG folder and output folder are
     remembered separately).
   - The **output folder** takes care of itself: it becomes "<that folder>\PDF" and is created on the
     run. Use *Browse* to change it, *Default* to go back.
   - **Output per DWG**: "Merge into one PDF" (default, named after the DWG) or "One PDF per sheet"
     (named after the sheet).
   - **"LAYOUT sheet first, BOM sheet second when merging"** is **off by default** (since v2.3.0).
     Ticked: the LAYOUT (arrangement) sheet goes to page 1, the BOM sheet to page 2, the rest keep their
     order; if it cannot be decided the original order is kept and the log says so. Page order otherwise
     follows the layout tab order you see in AutoCAD.
   - **Paper size** defaults to **A1** (since v2.3.0): a sheet smaller than A1 (A3/A4 details, system
     diagrams) is scaled up so the text is bigger and the print sharper; a sheet larger than A1 (A0
     layouts) keeps its own size and is never shrunk. A0/A2/A3/A4 and "Auto (use the sheet's own size)"
     are available.
   - Tick "Include sub-folders" to walk the whole tree; "Mirror folder structure in output" is on by default.
   - Click **Start**.
5. **The first run has to start AutoCAD: the log sits at "starting / connecting to AutoCAD" for 30-60 s.
   That is normal.** Do not touch or close AutoCAD while a run is in progress.

3. Where the results are
------------------------------------
The PDFs are in the output folder.
- Default: one multi-page PDF per DWG (named after the DWG), one page per sheet, in layout-tab order.
- Empty layouts left over in a DWG (布局9, 布局10 ...) do not become blank pages (since v2.5.0);
  the log says "empty layout, no page".
- "One PDF per sheet": one PDF per layout, named after the layout or the title-block title.
- A few drawings have their paper and geometry misaligned; the app re-fits the window to the drawing
  (1:1 when it fits, "fit to paper" when it does not) so nothing is cropped.

4. When something goes wrong
------------------------------------
1. Read **run.log** next to the exe: it records whether a click reached the backend and what failed.
2. Common cases:
   - "Cannot start AutoCAD": not installed / not licensed / blocked by UAC (try "run as administrator").
   - "AutoCAD is busy ... retrying": normal during plotting, the app retries by itself.
   - Large white margins around the drawing: the frame is only a fraction of the paper; since v2.1.3 the
     frame is fitted to fill the page, leaving 1 mm.
   - A whole page is blank (only the paper edge): the DWG carries an unused empty layout; since v2.5.0
     those pages are dropped and listed in the log.
   - A page has only the frame and title block: the viewport is empty / layers off / xref missing;
     since v2.5.0 the log warns "almost no graphics ... please check".
   - "duplicate title block: sheet N and sheet M are identical": the drawing really contains two identical
     frames (since v2.6.0 the log names them). Not an app error — delete the extra frame in CAD and re-run.
   - Antivirus blocks the exe: add it to the allow-list (PyInstaller one-file exes often trigger this).
   - The page does not open: port taken, close the old exe process and double-click again.
   - The picker does not start where expected: delete dwg2pdf_state.json next to the exe
     (it stores only paths and the language).
   - The UI is in the wrong language: press the `中文` / `English` button; to follow the system again,
     set "lang" to "auto" in dwg2pdf_state.json.
3. Do not double-click several copies: the app reuses the running backend and just opens another tab.
4. **New exe, same old behaviour?** Check the version next to the title. If it shows the old version, the
   old backend is still running: press "Quit" in the page, or end DWG2PDF.exe in Task Manager (v1.9.1+
   detects and closes the old instance automatically).

5. Uninstall / move to another PC
------------------------------------
There is no installer: delete the exe. To move, copy the exe (or this whole folder) to the other PC.
The files the app may leave next to it can be deleted too:
run.log, dwg2pdf_state.json (last folder + language), start_error.log (only after a failed start).
