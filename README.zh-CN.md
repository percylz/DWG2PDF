# DWG 批量转 PDF

[English](README.md) | 简体中文

把指定文件夹里所有 DWG 的**每一张图纸（布局）分别打印成一个 PDF**，文件名默认取图纸名，可加统一前缀。

比如一个 DWG 里有「一层平面图 / 二层平面图 / 屋顶排水图」三张图纸，
加前缀 `A-` 后就会得到三个文件：`A-一层平面图.pdf`、`A-二层平面图.pdf`、`A-屋顶排水图.pdf`。

---

## 一、怎么用（推荐：双击 exe）

双击 **`DWG2PDF.exe`** → 浏览器自动打开操作界面：

1. 选「DWG 所在文件夹」（默认会连同子文件夹一起处理）；
2. 「PDF 输出文件夹」不用管：选好上面那个文件夹后，这里会自动填成 `该文件夹\PDF`，
   转换时**自动新建**这个 `PDF` 文件夹（想放到别处再点「选择…」，点「默认」可随时改回来）；
3. 在「一个 DWG 的输出」里二选一：
   - **合并成 1 个 PDF（多页，每页一张图纸）** —— 默认，文件名用 DWG 名；
   - **每张图纸各出 1 个 PDF** —— 文件名用图纸名；
4. 需要的话勾上「合并时 LAYOUT 图排第 1 页、BOM 图排第 2 页」（v2.3.0 起**默认不勾**，见下节）；
5. 「纸张大小」默认 **A1**：图纸比 A1 小（例如 A3/A4 的配电盘详图、系统图）就等比放大到 A1 出图，
   **字更大、打印更清楚**；图纸本身比 A1 大（A0 的布置图）则保持原尺寸，**不会被缩小**。
   也可以选 A0 / A2 / A3 / A4，或选「自动（按图纸本身尺寸）」回到按图取纸的老行为；
6. 需要的话填「文件名前缀」，例如 `A-`；
7. 点 **开始转换**，日志会逐张打印进度，结束后可直接打开输出文件夹。

> **页序规则（v2.0.1 起提供，v2.3.0 起默认关闭）**：勾选后，合并成一个 PDF 时程序会把
> **LAYOUT（布置图）提到第 1 页、BOM（物料清单）提到第 2 页**，其余图纸保持原来的图纸顺序。判断依据依次是图纸名（布局名 / 图框标题）
> 和该页 PDF 里的文字（`LAYOUT` / `LAYOU` / `布置图`，`BOM` / `BILL MATERIAL` / `物料清单` / `设备清单`）。
> 认不出来、或者同类型图纸不止一张时，自动保持原顺序，日志里会写明，不会把图序搞乱。
> 要这个行为就把勾选框勾上，或命令行加 `--page-order`；不加就完全按图纸顺序出（v2.3.0 起的默认）。

> **纸张大小（v2.3.0 起）**：只放大不缩小——纸比图大就按你选的纸出（图等比放大，字更大更清楚），
> 图比纸大就保持图的原尺寸（缩小只会更糊）。日志里会写「按界面选定的 A1 出图（841x594 mm，图纸 … 等比放大）」，
> 同一张纸只提示一次。

> 点「选择…」打开的是程序自带的文件夹选择器（大窗口、大字），左侧是常用位置与盘符，
> 中间双击进入子文件夹、单击选中，也可以把路径直接粘到上方输入框按回车跳转；
> 下方会提示当前文件夹里有几个 DWG。

> 这个 exe 是单文件、免安装的：拷到 U 盘或别的电脑都能直接双击运行，
> **不需要装 Python**，只要那台电脑装了 AutoCAD 即可。

> 转换时 AutoCAD 在后台运行（看不到窗口）。首次启动约 30 秒，
> 日志出现「已连接 AutoCAD」之后就是正常的出图速度了。
> 想下次更快，可以勾选「转换后保留 AutoCAD 进程」。

### 用源码方式启动（改了代码后想立刻试）

双击 **`start.bat`**，效果与 exe 完全一样，只是走本机 Python 环境。

## 二、怎么用（命令行 / 批处理）

```bat
:: 基本用法：整个文件夹 → 指定输出目录
python dwg2pdf.py -s "D:\项目\建筑图" -o "D:\出图\PDF"

:: 加文件名前缀
python dwg2pdf.py -s "D:\项目\建筑图" -o "D:\出图\PDF" -p "A-"

:: 只转新增（断点续转，已生成的跳过）
python dwg2pdf.py -s "D:\项目\建筑图" -o "D:\出图\PDF" -p "A-" --skip-existing

:: 先看会生成哪些文件，不实际出图
python dwg2pdf.py -s "D:\项目\建筑图" -o "D:\出图\PDF" -p "A-" --dry-run

:: 单独一个 DWG 也可以
python dwg2pdf.py -s "D:\项目\建筑图\建筑A.dwg" -o "D:\出图\PDF"
```

### 参数一览

| 参数 | 说明 |
|------|------|
| `-s, --src` | 源文件夹（或单个 .dwg 文件），必填 |
| `-o, --out` | PDF 输出文件夹，必填，不存在会自动创建 |
| `-p, --prefix` | 文件名前缀，默认空 |
| `-t, --tpl` | 命名模板，默认 `{prefix}{layout}`，占位符：`{prefix}` 前缀、`{layout}` 图纸名、`{dwg}` 源文件名、`{n}` 序号 |
| `--include-model` | 同时导出模型空间（默认只导图纸布局） |
| `--frames` | 强制按模型空间图框拆分（每张 A0-A4 图框一个 PDF） |
| `--layouts` | 只按图纸布局输出，不做图框拆分 |
| `--no-recursive` | 只处理第一层，不进子文件夹 |
| `--keep-subdir` | 输出目录中保持源文件夹结构 |
| `--skip-existing` | 跳过已存在的 PDF，适合断点续转 |
| `--pc3` | 强制使用指定打印设备，默认 `DWG To PDF.pc3` |
| `--one-pdf` | 一个 DWG 只输出一个多页 PDF（默认行为，可省略） |
| `--split` | 每张图纸各输出一个 PDF（旧方式，v2.0 之前的行为） |
| `--paper A0..A4\|auto` | 出图纸张，默认 `A1`（只放大不缩小）；`auto` = 完全按图纸自身尺寸 |
| `--page-order` | 合并时把 LAYOUT 图排第 1 页、BOM 图排第 2 页（默认不排） |
| `--no-page-order` | 明确不要调页序（默认行为，写出来只是让脚本更清楚） |
| `--dry-run` | 只列出将生成的文件，不出图 |
| `--check` | 只检查 AutoCAD 是否可用、有多少个 DWG |
| `--keep-acad` | 转换完保留 AutoCAD 进程（下次启动更快） |
| `--json` | 输出机器可读的结果（便于接入其它流程） |
| `--log 文件` | 同时把日志写入文件 |

退出码：`0` 全部成功，`2` 有失败，`3` 环境/运行错误。

## 三、一个 DWG 里有多张图纸怎么办

界面上「一个 DWG 的输出」有两种方式，选哪个就按哪个走：

| 方式 | 结果 | 文件名 |
|------|------|--------|
| **合并成 1 个 PDF**（默认） | 一个 DWG → **1 个多页 PDF**，一页一张图纸，每页保留自己的幅面（A0/A1/A3 混排也不会被统一）；页序就是图纸顺序（勾了「LAYOUT 排第 1 页、BOM 排第 2 页」才调整） | 用 **DWG 的文件名**（可加前缀） |
| **每张图纸各 1 个 PDF**（旧方式） | 一个 DWG → N 个单页 PDF | 用 **图纸名**（布局名或标题栏图名） |

程序还会自动判断这些图纸是「布局」还是「模型空间的图框」：

**1）图纸画在「布局」里（有多个 Layout）** → 按布局逐张出图，再按上面选的方式合并或分开。

**2）所有图都排在模型空间里（没有可用布局）** → 程序按**图框**拆分，每张图框算一张图纸
（合并模式下就是多页 PDF 里的一页）：

- 识别依据：图框块的命名约定 `A0 / A1 / A2 / A3 / A4`（块内那个最大的闭合矩形就是图框）；
  没有这种命名时，退而识别尺寸等于「标准图幅 × 常见比例」的矩形（如 118900×84100 = A0×1:100）。
- **每张 PDF 的页面自动用该图自己的图幅**（A0 / A1 / A2 …），并按窗口出图、布满图纸，
  也就是 1:100 的图仍然按 1:100 出，不会被统一成一种纸张。
- **图名取该图标题栏里的文字**（如「一层动力平面图」）；取不到时退回图号（如 `FD-12`），
  再取不到就是 `图纸01`。合并模式下这些图名就是日志里的「第 n/m 张：xxx」。
- 只有在「布局全空」时才启用图框拆分，所以已有布局的图纸不会被改变输出方式；
  想强制按图框拆，用 `--frames`；想强制只用布局，用 `--layouts`。

实测样例 1（`某数据中心---电气图纸.dwg`）：模型空间里 16 张图（A0×5、A1×9、A2×2），
合并模式下输出 1 个 16 页 PDF，页幅分别是 1189×841、841×594、594×420 mm。

实测样例 2（`1-IP DDC-AC- ICT2.dwg`，13 个布局，全是 A4 横版）：
合并模式 → 1 个 `1-IP DDC-AC- ICT2.pdf`（13 页，5.2 MB）；分开模式 → 13 个 `布局1.pdf`…`布局13.pdf`。
合并结果的页序就是布局序号：**第 1 页 = 布局1（Panel Layout）、第 2 页 = 布局2（BOM）、…、第 13 页 = 布局13**。
（这份图里 LAYOUT 图正好是布局1、BOM 图正好是布局2，所以「LAYOUT 排第 1、BOM 排第 2」这条规则自然满足，不需要挪动。）

### 页序：按布局空间的序号排（v2.1.1）

合并成一个 PDF 时，页序 = 该 DWG 里**布局标签（选项卡）的先后序号**：
`布局1` → 第 1 页、`布局2` → 第 2 页、……，与你在 AutoCAD 界面下方看到的标签顺序一致。

- 依据是 AutoCAD 布局对象的 `TabOrder`（标签真实位置），**不是**名字的字母序。
  这一点很关键：`Layouts` 集合本身是按名称字母序返回的（`布局1、布局10、布局11、布局12、布局13、布局2…`），
  直接用它排序会把 `布局10` 排到 `布局2` 前面，v2.1.1 之前的版本就有这个问题。
- 布局名不是数字（如 `一层平面图`、`A-101`）时同样按标签顺序排，不做任何猜测。
- 万一取不到 `TabOrder`，退回按名字里的数字做自然排序（`布局2` 排在 `布局10` 前面）。
- 「每张图纸各出 1 个 PDF」时也是按这个顺序逐个出图，日志里的「第 n/m 张」就是这个顺序。

### 页序加强：LAYOUT 第 1 页、BOM 第 2 页（v2.0.1，默认开启）

在上面「按布局序号」的基础上，如果勾选了这个选项，合并前还会把 **LAYOUT（布置图）** 提到第 1 页、
**BOM（物料清单）** 提到第 2 页——用于那些布置图/物料清单排在后面布局里的图。
两类图本来就在前两页时，等于不做调整。

判断规则：

| 类型 | 命中关键词（不区分大小写、忽略空格和标点） | 排到 |
|------|--------------------------------------------|------|
| LAYOUT（布置图） | `LAYOUT`、`LAYOU`、`布置图` | 第 1 页 |
| BOM（物料清单） | `BOM`、`BILL OF MATERIAL`、`物料清单`、`设备清单` | 第 2 页 |
| 其它 | — | 保持原顺序 |

- 判断顺序：先看**图纸名**（布局名 / 图框标题栏图名），看不出再看**该页 PDF 里的文字**。
- **同类型图纸不止一张**（例如两张都叫 BOM）时，无法确定该把哪张放前面，**保持原顺序**，
  日志里提示「识别到 N 张 LAYOUT 图、M 张 BOM 图，无法唯一确定页序」。
- 一页里同时出现 `LAYOUT` 和 `BOM`（常见于布置图标题栏里印了 BOM 字段）也视为「其它」，不乱动。
- 页序调整只影响合并成的那一个 PDF；「每张图纸各出 1 个 PDF」不涉及页序。
- 关掉：界面去掉该勾选，或命令行加 `--no-page-order`。

## 四、命名规则

**合并成 1 个 PDF 时**，文件名取 DWG 名：

| 情况 | 结果 |
|------|------|
| 前缀留空 | `1-IP DDC-AC- ICT2.pdf` |
| 前缀 `A-` | `A-1-IP DDC-AC- ICT2.pdf` |
| 输出目录里已有同名 PDF | 自动加序号，如 `图纸 (2).pdf` |

**每张图纸各 1 个 PDF 时**，文件名取图纸名：

| 情况 | 结果 |
|------|------|
| 前缀留空 | `一层平面图.pdf` |
| 前缀 `A-` | `A-一层平面图.pdf` |
| 不同 DWG 里有同名图纸 | `一层平面图.pdf` + `一层平面图 - 结构B.pdf`（自动补源文件名，不会互相覆盖） |
| 还想带源文件名 | `-t "{prefix}{dwg}-{layout}"` → `A-结构B-一层平面图.pdf` |
| 勾选「保持目录结构」（v2.1.0 起默认勾选） | 输出目录按源文件夹分目录，重名互不影响 |

文件名里的 `\ / : * ? " < > |` 等非法字符会自动替换成 `_`。

## 五、出图保真度

- 走的是 AutoCAD 自己的出图流程（`PlotToFile`），**与在 CAD 里手工打印效果一致**：
  图幅、出图比例、打印样式表（CTB/STB）、线宽、图框块、外部参照的显示都沿用图纸原有设置。
- 图纸原来的打印设备是 PDF 设备（.pc3）时，完全按原页面设置出图；
  原来是打印机（或没设置），会切换到 `DWG To PDF.pc3` 并尽量还原原来的纸张尺寸。
- **图纸空间里内容偏离纸张**（在 CAD 里看到「白色纸面和图形错开」，甚至纸面上什么都没有）时，
  按图纸内容的实际范围重新框定窗口并居中：装得下就按 1:1 出图，装不下（内容比这张纸还大）
  就按「布满图纸」缩放到本页，**整张图完整、不裁切**，日志里会写明是哪一种。
  这种图在别的电脑上"看起来正常"，多半是那台机器的打印设备里有同名但尺寸不同的纸（自定义纸），
  程序不依赖那个设备，统一按内容重算。
- **图框只占纸张一小块**（例如图框 122×88 mm 配 A4 纸，整页只剩 41%）时，按图框把纸张铺满：
  图框不到纸张 80% 就不再坚持 1:1，改为「按图框铺满本页」；需要缩放时一律用满幅无边距纸，
  否则普通纸 5/17 mm 的可打印边距会在页面四周再留一圈白边。图框≈纸张（92% 以上）时仍然 1:1，比例不动。
- **只读打开**，不修改、不保存原始 DWG，也不会在图纸里留下任何痕迹
  （缺字体时的替换也只在内存里生效，落盘保存的仍是原图纸）。
- 图纸没设打印样式表时，会用 `monochrome.ctb` 黑白输出——否则颜色 7（白/黑）会打成白色，在 PDF 上看不见。
- 按图框拆分时，用「窗口 = 图框、纸张 = 该图图幅、布满图纸」出图，
  图框按 1:100 画就仍然是 1:100，与在 CAD 里选窗口打印一致。
- 默认只出「图纸布局」（Tab 上的那些布局），模型空间不出图；
  需要时勾选「同时导出模型空间」。若某个 DWG 只有模型空间，会按一张 `Model.pdf` 输出。

## 七、常见问题

| 现象 | 原因与处理 |
|------|------------|
| 换了新 exe，问题还在（现象和旧版一模一样） | 多半是**旧后台进程还没退出**：新 exe 检测到端口 8791 上已有本程序，就只把浏览器指过去，实际干活的仍是旧进程。v1.9.1 起启动时会比对版本号，发现旧版本实例会自动关掉再起新的，界面标题右边也会显示版本号（如 `v1.9.1`）；用旧版时请先在界面点「退出程序」，或在任务管理器结束 `DWG2PDF.exe` 再双击新的 exe |
| 生成的 PDF 只有一角有图、其余大片空白，或图被纸边裁掉 | 原图打印设备不是 PDF 设备（`Microsoft Print to PDF`、实体打印机驱动等），纸名（如 `A4`）在 DWG To PDF 里不存在，会被换成 Letter 竖版，而 1:100 是固定比例 → 图缩在一角。v1.9 起会按原纸物理尺寸找回同规格纸、按图纸内容重新框定并居中、画到纸边的图改用无边距纸；旧版请把图纸的打印设备改成 `DWG To PDF.pc3` 后重转 |
| 双击 exe 后浏览器没弹出 | 稍等 2~5 秒（exe 要先解压自身）；若仍没反应，看 exe 同目录是否生成了 `start_error.log`。也可手动打开 <http://127.0.0.1:8791/> |
| 杀毒软件报「可疑程序」或拦截 | 这是 PyInstaller 单文件 exe 常见的误报，加白名单即可；介意的话改用 `start.bat` 源码方式运行，功能一样 |
| 日志长时间停在「正在启动 AutoCAD」 | 首次启动 AutoCAD 需要 30~60 秒，属正常；超过 2 分钟请手动打开一次 AutoCAD，确认能正常启动、没弹授权/许可证提示 |
| 提示「没有找到 .dwg 文件」 | 检查路径；文件在子文件夹里要勾选「包含子文件夹」 |
| 一个 DWG 有十几张图，却只出了两三张空白 PDF | 说明这些图排在模型空间里，但图框没被识别到。确认图框块名是 `A0`-`A4`（或图框尺寸是标准图幅×整数比例），也可以加 `--frames` 强制按图框拆 |
| 拆出来的单张图内容被裁掉一点 | 图框的窗口范围就是图纸边界，画到框外的内容本来就不属于这张图；可在 CAD 里检查该图框 |
| PDF 里有整页空白（只剩纸边一条线，别的什么都没有） | DWG 里留着空的布局（通常是建模/拆分图纸时批量建出来、没用上的 `布局9`、`布局10`…）。这种布局在 AutoCAD 里手动打印同样是白纸。v2.5.0 起出完一页就判空，整页没有图形和文字的直接不出页，日志会列明跳过了哪几个布局；旧版请自行删掉 PDF 里的空白页，或在 CAD 里删掉这些空布局 |
| 某一页只有图框和标题栏，图本身没出来 | 该布局的视口里没有内容（视口指向空白区域、图层被关掉/在视口里冻结、外部参照没加载）。v2.5.0 起日志会提示「布局 × 几乎没有图形，只出到图框和文字，请核对」，按提示在 CAD 里检查该布局的视口和图层 |
| 个别图纸失败：没有生成 PDF | 程序会自动换 `DWG To PDF.pc3` 再试一轮（v1.1 起已修复「某些图纸静默失败」的问题）。若仍失败，说明该布局确实是空的，或页面设置里的打印设备在本机不存在且无法替代 |
| 转换成功，但 PDF 里大片内容空白（表格框线在、字没有） | 图纸引用了本机没有的字体（探索者 `tssdeng.shx`、`hztxt.shx`、PKPM 等）。AutoCAD 算不出这些文字的范围，出图时整段跳过。v1.4 起会自动把缺失字体临时换成宋体+GB 大字体（只改内存、不动原图），日志会提示「已临时替换」 |
| 中文变成问号或方框 | 图纸文字样式用的字体没有中文字形，属原图问题（CAD 里打印预览也一样），换字体即可 |
| PDF 内容被裁掉一部分 | 该布局的打印区域是「窗口」，且窗口范围本身框得不准；程序会照原样还原，可先在 CAD 里把页面设置改成「布局」或重设窗口再转 |
| 报「文件已打开」 | 该 DWG 正在 AutoCAD 里打开着，关掉再转 |
| 报「无法打开 / 文件不存在」 | 文件被占用、损坏，或由更高版本 CAD 保存（需同版本或更高版本打开） |
| 某个 DWG 的每张图都是空白，或只有中间一小块 | 这类 DWG 的图纸空间内容不在纸张矩形里（在 CAD 里看就是白纸和图形错开），按原页面设置出图自然是空白。v2.1.2 起会自动按图纸内容的实际范围重算窗口：装得下 1:1，装不下按「布满图纸」，并在日志写明 |
| 每页四周有一大圈白边、图缩在页面中间 | 这张图的**图框只有纸张的几分之一**（页面设置和图纸对不上，例如图框 122×88 mm 配 A4）。v2.1.3 起按图框铺满纸张、四周只留 1 mm |
| 页面上下有大片空白、左右被裁掉一截 | 图纸是横的，但页面设置里那张纸只有竖版写法（`DWG To PDF` 的 A0 就是 841×1189）。v2.1.1 之前的逻辑会把纸当横的算，1:1 出图就左右开刀。v2.2.0 起按纸的实际方向 + 出图旋转算真实页幅，横图自动出成横版页并铺满 |
| 一个 DWG 明明有好几张图，却只出了一页，图被压成细细一条 | 这几张图是**并排画在模型空间**、外面只套了一个装饰大框，图之间没有分割线。v2.2.0 起，外框又长又扁（长宽比 ≥1.8）时会找框内重复出现的同款图签块，按它们一张页拆开（实测 3 张并排 → 3 页） |
| 转换很慢，一页要等十几二十秒 | 图纸原来的打印设备出不了 PDF（例如同事自定义的 `M_PDF.pc3`，本机没有这个绘图仪配置）：AutoCAD 收到指令既不报错、也不生成文件，程序只能等超时再换设备。v2.4.0 起只认 AutoCAD 自带的 PDF 设备，其余直接用 `DWG To PDF.pc3`，不再白等 |
| 图纸很复杂时，识别图纸要十几秒 | 图里块参照/文字特别多（例如 2395 个块参照、2317 个文字）时，每次向 AutoCAD 取一个属性约 1~3 ms，逐个取就很慢。v2.4.0 起先取名字/位置再筛，2395 个块参照的图从 26 秒降到 13 秒 |
| 一页里挤了三四张图，却没有外框、没有分割线 | 这几张图是「整张图纸做成一个块（图签块）」并排画的，模型空间里根本没有图框。v2.3.0 起会找同名同尺寸、互不重叠、加起来占其并集 ≥85% 的块，按它们一张一页拆开（实测 4 张并排 → 4 页）。若块名不同、或每张尺寸不一样，仍会当一页出 |
| 图只占纸的左半边，右边一大片空白 | 页面设置里的「打印窗口」比纸还大（例如窗口 1690×841 mm 配 A0 的 1191×843 mm），按窗口 1:1 出图就只剩半页。v2.3.0 起出图前会检查，窗口超出纸幅就按图纸内容重新框定（实测 49.6% → 100%） |
| 打印出来字太小 / 看不清 | 把界面上的「纸张大小」调到 A1 或 A0：图纸比纸小会等比放大（A4 的详图放大到 A1 约 2.8 倍），图纸比纸大则保持原尺寸不缩小。要完全按图纸自己的幅面就选「自动」 |
| 空布局也生成了 PDF | 布局本身是空白图纸，会输出一张空白页，属正常 |
| 转换时每张 PDF 都被自动打开 | v1.2 起已修复：AutoCAD 前台出图后会按扩展名把结果「打开」一次，程序改为先写 `.part` 临时文件再改名，不再弹任何阅读器 |
| 输出目录里出现 `.part` 文件 | 出图中途被强制中断留下的临时文件，删掉即可；同名重转会先清掉它 |
| 合并成一个 PDF 失败 | 会自动退回「每张图纸一个文件」，日志里有 `！合并成一个 PDF 失败：…`，结果不会丢。常见原因是本机缺 `pypdf`（源码方式：`pip install pypdf`） |
| 合并后的页序和我预想的不一样 | 从 v2.1.1 起，页序 = **布局空间的选项卡序号**（`布局1` 第 1 页、`布局2` 第 2 页……），依据是 AutoCAD 的 `TabOrder`，不再受名字字母序影响。唯一的例外是勾选了「LAYOUT 排第 1 页、BOM 排第 2 页」时这两类图会被提到最前（默认开启，某些图里本来就已是第 1、2 页，等于不调整） |
| 明明有 BOM / LAYOUT 图，页序没变 | ① 该选项被关掉了（界面勾选框或 `--no-page-order`）；② 图纸名和页面文字里都没有可识别的关键词；③ 同类型图纸不止一张，日志里会有「无法唯一确定页序，保持图纸原顺序」；④ 这一页同时含 `LAYOUT` 与 `BOM` 字样，被当作「其它」。想让某张图排前面，可以在 CAD 里把图名/布局名改成含 `LAYOUT` 或 `BOM` 的名字 |
| 页序优化把不该提前的页提到了前面 | 去掉界面上的「合并时 LAYOUT 图排第 1 页、BOM 图排第 2 页」勾选，或加 `--no-page-order`，然后重转 |
| 想中断 | 界面上点「停止」，会在当前这张图纸出完后停下 |

## 八、文件说明

| 文件 | 作用 |
|------|------|
| `DWG2PDF.exe` | **打包好的可执行程序，双击即用，免安装、不需要 Python**（10.6 MB） |
| `start.bat` | 源码方式启动：用本机 Python 运行下面这套程序 |
| `dwg2pdf_ui.py` | 图形界面的本地服务（127.0.0.1，仅本机可访问） |
| `ui.html` | 界面页面（可选文件、改前缀、看日志与进度） |
| `dwg2pdf.py` | 核心程序：扫描 DWG、逐布局出图、命令行参数 |
| `build_exe.bat` | 改完代码后重新打包 exe |
| `app.ico` | 程序图标 |
| `QUICKSTART.txt` | 便携版使用说明（随 exe 一起拷到别的电脑时看这份） |
| `run.log` | 运行时自动生成的日志，记录页面载入、点击、异常（超过 512 KB 轮转为 `run.log.old`） |
| `start_error.log` | 仅当启动异常时才会生成，里面有详细报错 |

结束程序：界面上点 **「退出程序」**（exe 版没有命令行窗口，就靠这个按钮退出）；
用 `start.bat` 的话，直接关掉那个命令行窗口也可以。
